# DotEngine
This repository is my personal playground for exploring the Vulkan API. The goal is not to build a comprehensive engine or good even good engine architecture, but to experiment, learn, and create an environment for crafting cool effects (my goal is learning about graphics programming, not engine programming although closely related).

The baseline structure of this project is inspired by vkquide and Little Vulkan Engine (two very good learning resources for vulkan). The project serves as a canvas for my experiments with real-time rendering techniques, shader development, and high-performance graphics programming.
